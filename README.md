# ecommerce-ab-testing-project.
# Анализ результатов A/B/C-тестирования маркетинговой Email-кампании

## Бизнес-контекст проекта
Интернет-магазин запустил масштабную Email-кампанию по удержанию (Retention) клиентов из целевого сегмента **«Deal Seekers»**. 

**Цель эксперимента:** проверить, как два новых варианта писем (`Variant_A` и `Variant_B`) влияют на конверсию в покупку (CR) и доход компании по сравнению с текущим решением (`Control`).

## Технологический стек
* **Язык программирования:** Python
* **Библиотеки:** Pandas, NumPy, Matplotlib, Seaborn, Statsmodels (модуль `stats`)

## Ключевые этапы реализации проекта
1. **Предобработка и очистка данных:** Проведен аудит логов. Выявлена критическая техническая ошибка сплитования: **448 пользователей** одновременно попали в несколько тестовых групп. Данные пользователи были полностью исключены из выборки для предотвращения искажения стат-тестов.
2. **Расчет финансовых метрик:** Реализован расчет чистой выручки (`Net Revenue`) с учетом отфильтрованных возвратов (`refund_flag`). Рассчитаны продуктовые метрики: CR (Conversion Rate), AOV (Average Order Value) и ARPU (Average Revenue Per User).
3. **Статистическая проверка гипотез:** Применен **Z-тест для долей** (двухсторонний) с критическим уровнем значимости $\alpha = 0.05$.
4. **Визуализация:** Построены графики доверительных интервалов метрик (95% Wilson) и графики стабилизации накопительной конверсии по дням для подтверждения длительности теста.

## Результаты эксперимента

| Метрика | Группа Control | Группа Variant_A | Группа Variant_B |
| :--- | :---: | :---: | :---: |
| **Уникальные пользователи** | 10,416 | 3,326 | 3,354 |
| **Покупатели (чистые)** | 973 | 329 | 381 |
| **Конверсия (CR, %)** | **9.34%** | **9.89%** | **11.36%** |
| **Средний чек (AOV)** | 95.08 у.е. | — | 94.18 у.е. |
| **Доход на пользователя (ARPU)** | 8.06 у.е. | — | 10.00 у.е. |
| **p-value (vs Control)** | — | *0.3454* | **0.0006** |

### Главные инсайты:
* **Variant_A не показал статистической значимости** (p-value = 0.345 > 0.05). Небольшой рост конверсии носит случайный характер. Вариант отклонен.
* **Variant_B показал высокую статистическую значимость** (p-value = 0.0006 < 0.05). Вероятность случайной ошибки составляет всего 0.06%. 
* Несмотря на незначительное снижение среднего чека (AOV) в Variant_B (с 95.08 до 94.18 у.е.), за счет сильного роста конверсии итоговая доходность на одного пользователя (**ARPU**) выросла на **1.94 у.е.** (прирост доходности на +24%).

## Экономический эффект (Бизнес-вывод)
При масштабировании успешного решения **Variant_B** на всю платформу (при условном ежемесячном охвате подобных кампаний в 150,000 уникальных пользователей данного сегмента) прогнозируемый финансовый эффект составит:
* **+291,000 у.е.** дополнительного дохода в месяц.
* **~3,492,000 у.е.** дополнительной прибыли в год.
